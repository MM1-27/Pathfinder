Visualiser tool for 4 pathfinding algorithms: BFS, DFS, Dijkstra and A*
Instructions:
    Left click for walls
    Right click to place the starting point
    Press down scroll wheel to place the endpoint
    Press the key corresponding to the algorithm you would like to run:
        'b' for BFS
        'd' for DFS
        'k' for Dijkstra
        'a' for A*
Each of the squares that the algorithm searches will turn blue
When it reaches the endpoint, the final'quicket path it found will be highlighted in cyan
